# cc-v2

開発用のテンプレートリポジトリ。新しい案件は、このリポジトリをコピーして始める。

## 使い方

1. このリポジトリをコピーする（GitHub の "Use this template"、またはクローンして別リポジトリとして push）。
2. コピーしたリポジトリを開き、AI コーディングツールでセッションを開始する。
3. コピーしたリポジトリでセッションを始め、`in` と言う。前回の引継ぎが無ければ、そのまま初期設定
   （`setup`）が始まる。作業を終えるときは `out` と言う。
4. 以降の進め方は `AGENTS.md` に従う。`AGENTS.md` に「未記入」が残っている間は `setup`
   （`.claude/skills/setup/`）が走り、既にプロダクトのコードがあれば「取り込み」、まだ無ければ
   雛形づくりから入る。
5. `main` の branch protection はコピーで運ばれないので、公開するときに1回だけ設定する
   （`setup` の手順7、または `bash scripts/setup.sh`）。

同梱の `apps/web` / `packages/ui` は記入済みの見本。新しい案件では `setup` が最初に削除する。
