# 引継ぎメモ（handoff）

セッションをまたぐ**揮発的な引継ぎメモ**。**このファイルは毎回上書き**（最新1件だけを保持する）。
過去の失敗の蓄積は `docs/failures.md`（append-only・消さない）を見る。

（まだ何も実施していません。このテンプレをコピーした直後の初期状態です）

## ②今回トラブル

無し

## ③次回やる事

このコピー先で最初にやること：
1. 何を作る／持ち込むかを確認する（ゼロからの新規開発 か、既に完成しているプロダクトの持ち込み か）。
2. **新規開発**の場合：`AGENTS.md`「新規案件の初期化フロー」（手順0：機械強制の有効化 → 手順1-5：
   ヒアリング→リサーチ→提案→承認→設定）に従う。
3. **既存プロダクトの持ち込み**の場合：手順0（機械強制の有効化）は同様に行った上で、コードをそのまま
   配置し、`AGENTS.md`（`presets/_TEMPLATE.md` を複製）に現状のスタックを記載するだけでよい
   （ゼロから作り直さない）。持ち込むスタックが同梱サンプルと異なる場合は `.github/workflows/ci.yml`
   を実コマンドへ書き換えること。
