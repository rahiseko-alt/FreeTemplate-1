# 引継ぎメモ（handoff）

セッションをまたぐ**揮発的な引継ぎメモ**。**このファイルは毎回上書き**（最新1件だけを保持する）。
過去の失敗の蓄積は `docs/failures.md`（append-only・消さない）を見る。

## ①今回実施

`AGENTS.md`「新規案件の初期化フロー」のヒアリング部分を作り直した。旧版は「決めるべき必要項目」として
クラウド/言語/フレームワーク/パッケージ管理/DB/認証/IaC/テスト/CI/Lintの10項目を非エンジニアにゼロから
答えさせる形だったが、「毎回聞かれても分からない、鉄板の構成があるはず」という指摘を受け、以下に変更：

- **鉄板構成（デフォルト）を明記**：特別な事情が無ければ Vercel + TypeScript + Next.js + pnpm +
  Vitest + ESLint（＝ `apps/web/AGENTS.md` の実例そのもの）を使う、とAGENTS.mdに明記。
- **ヒアリングをFAQ形式に変更**：クラウド・既存システム連携・認証・データ保存・言語の5項目だけを、
  非エンジニアにも即答できる平易な質問（例：「使う人がログインする必要がありますか？」）にし、
  「いいえ」なら鉄板のまま、「はい」の場合だけ分岐して構成を変える形にした。
- パッケージ管理・IaC・テスト・CI・Lintは、クラウド/言語が決まれば自動的に付随するものとして
  ヒアリング対象から外した（非エンジニアに聞いても答えが出ない項目は質問にしない）。
